# Support

Kemlock-core is a library, used by the Kemlock app and the Kemlock browser extension. If you use
one of them and something is wrong, ask there; this repository is for the shared code.

- **A question about using the package**: read the [README](README.md) first, then search the
  [issues](https://github.com/Arsslensoft/Kemlock-core/issues). If it is not there, open a new one.
- **A bug**: open an issue with the bug report form. Say the commit or version, the Dart version,
  and the smallest code that shows it. Do not paste a vault, a password, a key, a code or a sync
  address.
- **An idea**: open an issue with the feature request form.
- **A security problem**: do not open an issue. Report it privately, as [SECURITY.md](SECURITY.md)
  says.
- **The Kemlock app or Kemlock Server**: their repositories are private for now. Ask here, and the
  question will be passed on.

To change the code, see [CONTRIBUTING.md](CONTRIBUTING.md).
